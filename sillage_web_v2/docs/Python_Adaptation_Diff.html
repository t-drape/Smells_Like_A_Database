    cursor = connection.cursor(dictionary=True)
    sql = """
    SELECT Fragrance.Fragrance_Name,

COMPATIBILITY CORRECTION · NOVEMBER 9, 2026

Team-desk password hashing

The reported AttributeError occurs when the loaded hashlib module lacks scrypt. The original app.py used that function to hash the temporary team-desk password at startup and to verify login attempts. This is separate from MySQL authentication.

Exact scope and justification

  • app.py: replace scrypt with PBKDF2-HMAC-SHA256 using 600,000 iterations. Retain the existing 16-byte random salt and hmac.compare_digest comparison. Both password creation and verification call the same updated function.
  • app.py: check that PBKDF2 is available before enabling team-desk login, and turn its missing-function error into an actionable command-line message. A server with staff login disabled can still start.
  • tests/test_web.py: simulate hashlib with PBKDF2 but no scrypt; verify server startup, rejection of a wrong password, acceptance of the correct password, and the resulting staff session. A second test covers missing PBKDF2 and the staff-disabled case.
  • README.md, docs/FEATURE_ADDITIONS.md, and this report: describe the correction and current verification.

No database adapter, student module, SQL file, SQL statement, grant, or transaction was changed for this correction. The existing student files were compared byte-for-byte with the preceding download. The team-desk digest exists only in the running process, so no stored hash migration is necessary.
