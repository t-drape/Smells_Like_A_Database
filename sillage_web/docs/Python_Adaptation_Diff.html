CONTEXT FOR ALL THREE FILES

What moved to the web application

The original files mixed connection setup, database functions, terminal prompts, and immediate execution. The adapted files contain callable functions. The new web code supplies a connection and values, calls the function, and presents the result.

The same definition-time rule applied to get_store() and get_discount_date(). The original discount cutoff was captured once when the module loaded. The service now calculates date.today() - timedelta(days=30) when called without a cutoff, while the website form can supply a different date.

Behavior beyond these three files

  • The ingredient query always returned all classifications, but the old print helper showed only clean fragrances. The new report shows all classifications.
  • The old revenue formatter attempted float(TotalRevenue). An empty SQL SUM can be NULL, which would fail that conversion. The new website displays an empty total as $0.00 and reports that no matching purchases were found. The SQL itself is unchanged.
  • The removed discount print helper claimed the customer had not purchased since each returned date. The query does not establish that. The new report labels the actual older-purchase rows and sends no messages.

These are presentation and orchestration changes. Saying “only the function signatures changed” would be incomplete. Saying “the retained SQL and parameterization were preserved” is supported by the comparison.

import mysql.connector


def stock_location(connection, fragrance_name):
    cursor = connection.cursor(dictionary=True)
    sql = """
    SELECT Store.City, Store.Building, Store.Street, Store_Inventory.Num_Bottles
    FROM Fragrance
      JOIN Store_Inventory
        ON Fragrance.Fragrance_ID = Store_Inventory.Fragrance_ID
      JOIN Store
        ON Store_Inventory.Store_ID = Store.Store_ID
    WHERE Fragrance.Fragrance_Name = %s
    AND Store_Inventory.Num_Bottles > 0
    ORDER BY Store_Inventory.Num_Bottles DESC;
    """
    cursor.execute(sql, (fragrance_name,))
    rows = cursor.fetchall()
    cursor.close()
    return rows


def top_seller(connection):
    cursor = connection.cursor(dictionary=True)
    sql = """
    SELECT Fragrance.Fragrance_Name,
           COUNT(*) AS Total_Purchases
    FROM Purchase_Record
      JOIN Fragrance
        ON Purchase_Record.Fragrance_ID = Fragrance.Fragrance_ID
    GROUP BY Fragrance.Fragrance_ID, Fragrance.Fragrance_Name
    ORDER BY Total_Purchases DESC
    LIMIT 5;
    """
    cursor.execute(sql)
    rows = cursor.fetchall()
    cursor.close()
    return rows
